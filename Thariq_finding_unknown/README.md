# Thariq_finding_unknown

Seven-skill series operationalizing Thariq Shihipar's (Anthropic, Claude Code team) "map is not the territory" methodology — the unknowns four-quadrant framework (known knowns / known unknowns / unknown knowns / unknown unknowns) applied to agentic coding work.

See the main repo [README](../README.md#finding-unknowns-series-thariq_finding_unknown) for the full description of each skill and how they compose.

| Skill | Stage | Thariq technique |
|---|---|---|
| `map-vs-territory` | Diagnostic entry point | Map vs. territory + four quadrants |
| `blindspot-pass` | Pre-work | Blindspot Pass |
| `reference-anchor` | Pre-work | References |
| `decision-first-plan` | Pre-work | Implementation Plan |
| `deviation-log` | During execution | Implementation Notes |
| `comprehension-quiz` | Pre-acceptance | Explainer & Quiz |
| `verify-with-rubric` | Pre-acceptance | Self-referential bias / decoupled verification |

Note: to make these skills triggerable by Claude Code, install each `<name>/` folder directly under `~/.claude/skills/<name>/` (flat, not nested) — this repo folder is the versioned/organized copy, not the load path.
