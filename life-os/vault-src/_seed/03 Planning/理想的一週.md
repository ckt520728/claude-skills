一個模板週，不是行程表。它只回答一個問題：**我說重要的那些事，時間實際在哪裡？**
每次退修重寫，每次週記檢查。

## 格子
第一次退修時填上你真實的一週（門診、病房、研究、家人、運動、閱讀、夜間評分）。

| 時段 | 一 | 二 | 三 | 四 | 五 | 六 | 日 |
|---|---|---|---|---|---|---|---|
| 早上 |  |  |  |  |  |  |  |
| 上午 |  |  |  |  |  |  |  |
| 中午 |  |  |  |  |  |  |  |
| 下午 |  |  |  |  |  |  |  |
| 傍晚 |  |  |  |  |  |  |  |
| 晚上 |  |  |  |  |  |  |  |
| 睡前 | 夜間評分 | 夜間評分 | 夜間評分 | 夜間評分 | 夜間評分 | 夜間評分 | 夜間評分＋下週計畫 |

## 規則
- 退修定下的意圖，先拿到固定時段，其他事才排進來。
- 深度工作時段受保護。
- 夜間評分那 30 秒不可協商：整個系統都站在它上面。
