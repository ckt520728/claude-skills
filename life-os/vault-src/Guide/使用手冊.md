# 📘 Life OS 使用手冊

> 一句話：**每晚 30 秒評分，其他都是這件事長出來的。**
> 這套系統照 Compass（Mike Schmitz 的系統、Daniel Agrici 的 Obsidian 模板）的結構蓋在你原本的第二大腦上，
> 再把 GTD 裡「分類、判斷」的工作交給 JEV 決策層。

---

## 0. 這是什麼

### 三件事，各由誰做

| 層 | 誰做 | 做什麼 | 例子 |
|---|---|---|---|
| **[C] 程式** | `lifeos/` Python、儀表板 JS | 算得出對錯的事 | 7 日平均、連續天數、今天第幾天、哪一層解鎖 |
| **[D] JEV 決策層** | `jev-engineering` 技能（本機、免費、0.1 毫秒） | 從固定選項挑一個標籤，附上**校準過**的信心 | 這則收件可以行動嗎？哪一類？多急？ |
| **[G] 大型語言模型** | Claude（透過 `Prompts/`） | 要寫給人看的文字 | 夜間教練、週回顧、退修引導 |

判斷方式：錯了算術抓得到 → [C]；答案是固定選項之一 → [D]；答案是一段人要讀的話 → [G]。

### 資料夾地圖（Compass 結構，全部在 `Life OS/` 底下）

| 資料夾 | 是什麼 | 誰寫 |
|---|---|---|
| `00 Dashboards/` | [[指南針儀表板]]、[[每日提問]]、[[習慣畫布]]、[[任務儀表板]]、[[專案儀表板]]、[[看板總覽]]、[[助理]]、[[設定清單]] | 部署（別手改） |
| `01 Journal/Weekly`、`Quarterly` | 週記、季記 | **你** |
| `02 Retreats/` | 每季個人退修 | **你** |
| `03 Planning/` | [[人生主題]]、[[核心價值]]、[[理想的一週]] | **你** |
| `04 Projects/` | 專案筆記、[[專案看板]] | **你** |
| `05 People/` | 人物筆記 | **你** |
| `06 Writing/` | [[創作看板]]（作品本身還是放 `創作庫/`） | **你** |
| `08 Tasks/` | [[任務總表]]：收件匣 | **你**（透過捕捉熱鍵） |
| `Meta/` | [[Compass Config]]（唯一設定檔）、`views/`（儀表板程式） | 設定檔是你的；views 是部署的 |
| `Prompts/` | AI 的工作說明書，一件事一則 | 部署 |

| `scripts/` | `nightly.js`（夜間評分）、`capture.js`（收件） | 部署 |

**每日筆記不搬家**，仍然在 vault 的 `每日筆記/`，沿用你原本的「🏥 臨床／💡 今日反思／明日優先事項」結構，另外多了「📝 日記／🏆 今日小勝／🙏 感恩」三個捕捉區。

## 1. 第一次設定（約 10 分鐘）

照 [[設定清單]] 一項一項勾。重點：

1. **開 Dataview**：`設定 → 第三方外掛 → Dataview` → 開；Dataview 設定裡開 **Enable JavaScript Queries**。
2. **在 QuickAdd 建兩個 Macro**（這一步以前沒做，所以 `Ctrl+Shift+Q` 一直沒反應）：
   - `設定 → QuickAdd` → 在下方輸入名稱 `Life OS 夜間評分`，類型選 **Macro** → Add Choice
   - 點它旁邊的 ⚙️ → **User Scripts** 下拉選 `Life OS/scripts/nightly.js` → Add → 關閉
   - 點它旁邊的 ⚡（變成黃色 = 已成為指令）
   - 同樣再建一個 `Life OS 收件`，User Script 選 `Life OS/scripts/capture.js`
   - 名稱要**一字不差**，儀表板的按鈕是用名稱找它們的。
3. **熱鍵**：`設定 → 快捷鍵`，搜尋 `Life OS`：夜間評分 → `Ctrl+Shift+Q`；收件 → `Ctrl+Shift+I`。
4. **改題目**：打開 [[Compass Config]]，把 `dq_questions` 那 4 題**草稿**改成你自己的（見第 11 章）。
5. 今晚按一次 `Ctrl+Shift+Q`。

> 想要有人陪你做：在 Claude Code 說「讀 `Life OS/Prompts/16 新手引導.md`，照它做」。

## 2. 每一天

| 時間 | 做什麼 | 花多久 |
|---|---|---|
| 早上 | 打開 [[指南針儀表板]] 看一眼。（想要 AI 幫你開場：`Prompts/01 晨間啟動`） | 1 分鐘 |
| 白天 | 想到任何事 → `Ctrl+Shift+I` → 選「📥 收件」→ 打一行。不用分類，**寫下來就好**。 | 5 秒／則 |
| 白天 | 值得記的事 → `Ctrl+Shift+I` → 選 📝 日記／🏆 小勝／🙏 感恩 | 5 秒 |
| 晚上 | `Ctrl+Shift+Q` → 每題 1–10 分 → 習慣是／否 → 一句反思（可空白） | **30 秒** |
| 睡前（選配） | Claude Code：「讀 `Prompts/02 夜間教練`，照它做」 | 3 分鐘 |

### 評分的兩條規則（來自 Goldsmith《Triggers》）
1. **問努力，不問結果。** 生病還跑了 3 公里可以是 10 分；不想跑就砍半，可能只有 5 分。
2. **空白可以跳過。** 累到只想答兩題，就答兩題。跳過不會把平均拉低，沒寫的那天也不算 0 分。

夜間評分是**只追加**的：分數寫進今天日記的 frontmatter，反思追加在「💡 今日反思」底下，既有文字一個字都不改。

## 3. 儀表板怎麼看

[[指南針儀表板]] 從上到下：

- **前往**：今天／本週／本季／本季退修。筆記不存在就**自動用模板建一則**（取代 Templater 與 Periodic Notes）。旁邊的按鈕：收件、夜間評分、新專案、新人物。
- **每日提問**：今天 vs 你自己的 7 日平均。重要的是**落差**（▲▼），不是絕對分數。平均旁邊的 `n=3/7` 是分母——只答了 3 天的「7 日平均」不是趨勢。下面是可切換題目與時間範圍的折線圖。
- **習慣**：● 做到　○ 有紀錄沒做到　· 那天沒日記。目前連續、最長連續、最長中斷、完成率。
- **人生輪**：本季退修的 `wheel_*` 雷達圖，最低分的領域就是下一季的候選焦點。
- **今天的任務**、**看板**。
- **臨床負荷**：只有數字（待處理幾例、負荷 1–5）。用途是**歸因**：門診重的那天閱讀分數低，是解釋，不是失敗。
- **往年今日**：往年同一天你寫的反思。「不是寫日記有用，是某天不經意撞見過去的自己。」
- **Memento mori**：填了 `birthdate` 才會出現。一格一年。
- **系統層級**：哪一層開了、哪一層還在等、為什麼。

## 4. 一層一層打開（Build Order）

Compass 作者的警告：「這套我花了五年蓋。請不要想在一個週末全部照抄——那是讓你從 Obsidian 彈開的最好方法。」
所以東西**全部都建好了**，但依照上游 `Guide/11 Build Order` 一層一層打開：

| 天數 | 打開的層 | 做到什麼算完成（上游定義） |
|---|---|---|
| 1–30 | 每日提問＋日記 | 30 天裡至少 25 天有評分 |
| 31–60 | 習慣畫布＋週記 | 連續 4 週做週回顧 |
| 61–90 | 第一次季度退修＋人生主題、核心價值、理想的一週 | 退修筆記完成、人生輪畫出來、3 個意圖放進週記 |
| 91–120 | 任務、專案、人物、GTD 自動歸檔 | 有一週是照任務儀表板＋時間塊過的 |
| 121+ | 創作看板 | 一件作品從靈感走到發表 |

**第二條規則也寫成程式了**：上一層一致性低於 80%，下一層不開。第 31 天到了，但近 30 天只評分 20 天（67%），習慣層就會顯示「日期到了，但一致性未達 80%」。

還沒開的層**不會藏起來**，會變灰、標出解鎖日；按「先偷看一下」可以看內容。
**收件（`Ctrl+Shift+I`）從第一天就開著**——捕捉不需要任何前置條件。

起算日是 [[Compass Config]] 的 `start_date: 2026-09-29`。

## 5. GTD 收件與 JEV 決策層

這是整套系統跟一般 Compass 最不一樣的地方。

### GTD 五個階段，各由誰負責

| 階段 | 問題 | 誰 |
|---|---|---|
| **捕捉** | 無——寫下來就好 | 你（`Ctrl+Shift+I`） |
| **釐清** | 可以行動嗎？兩分鐘／下一步／專案／參考／將來也許？哪個人生領域？ | **[D] JEV** |
| **組織** | 歸到 Clippings／知識庫／創作庫／任務？知識庫已經有類似的頁嗎？ | **[D] JEV**＋[C] 比對 index |
| **回顧** | 多急？多耗神？ | **[D] JEV** |
| | 分數是否低於 7 日平均？週回顧到了沒？ | **[C] 程式** |
| **執行** | 教練對話、寫反思 | **[G] Claude** |

### 怎麼用

收件匣累積了一些之後，在終端機（PowerShell 或 Git Bash）：

```bash
cd "G:\我的雲端硬碟\2026 Life OS"
python scripts/triage.py          # 逐則清空收件匣
python scripts/triage.py --demo   # 用範例句子試玩，不碰任何檔案
python scripts/triage.py --report # 看決策層目前有多可信
```

每一則收件，決策層做**一次**判斷（同時問完六題），然後給你建議：

```
[1/3] 明天打電話預約牙醫
  這則屬於哪一類？
    1) two_minute
    2) next_action     <- 建議
    3) project
    ...
    Enter 接受建議，或輸入編號 / s 跳過：
```

按 **Enter** = 同意；輸入**編號** = 改掉；**s** = 跳過。

### 為什麼它一開始什麼都問你

決策層的「信心」不是它自己說了算，是**用你的回答量出來的**：

- 一開始它是「冷的」：信心一律回報 0.30，低於任何門檻，所以**每一題都問你**。這是正確行為，不是故障。
- 你每按一次 Enter 或改一次，就是一筆「它對不對」的紀錄。
- 某一個信心區間累積 12 筆以上、而且大多是對的，那個區間才會「暖機」，開始自己歸檔。
- **老是錯的區間永遠不會暖機**，不管累積多少筆。
- 暖機之後，仍有 20% 的自動歸檔會抽出來請你確認（抽查），這樣它變差的時候看得出來。
- 碰到**臨床、金錢、他人**（病人、處方、匯款、生日、道歉……）的收件，**不管信心多高都問你**。
- 「知識庫」與「Clippings」永遠不自動歸檔（知識庫還要更新 index.md 與 log.md，目前沒有自動化）。

### 現在是影子模式

第 91 天（任務層）之前，triage **只提議、只學習，不寫入任何清單**。這不是等待，是訓練期：
你現在每一個回答，都讓它在第 91 天開始時已經有證據，而不是從零開始。

### 它哪裡會錯

決策層是比對字詞的，沒有常識、不懂同義詞、不懂否定。「張醫師」裡的「醫」可能讓它以為是健康類。
**這沒關係**——校準會讓它知道自己常錯，然後繼續問你。
如果 `--report` 顯示某一題你的同意率長期低於 70%，該做的是修改選項的描述字詞（第 11 章），不是降低門檻。

## 6. 每週回顧（第 31 天起）

1. 週日或週一：[[指南針儀表板]] →「本週」→ 自動建立週記。
2. 寫 **本週意圖** 3 件，每件都要能追溯到本季意圖。
3. 看一眼 [[理想的一週]]：這 3 件的時間放在哪？**現在**調行事曆。
4. 週五：週記下半部的表格自動列出每天的分數與習慣、自動收集這週的小勝。寫「順利的／不順的」。
5. 想要 AI 陪你回顧：`Prompts/03 每週回顧`。

---

## 7. 季度退修（第 61 天起）

一季一次、幾個小時、一則筆記。

1. [[指南針儀表板]] →「本季退修」→ 自動建立 `YYYY-QN 個人退修`，人生輪欄位直接從設定檔帶入。
2. 照筆記的 7 段走：人生主題與價值 → 回顧這季日記 → 人生輪評分（frontmatter 填 1–10）→ 回顧 → 開始/停止/繼續 → **下一季意圖（最多 3 個）** → 理想的一週 → 跟上次退修比。
3. 「本季」季記會自動嵌入退修的「下一季意圖」；週記再嵌入季記的意圖。一個來源，每個尺度都看得到。
4. 退修前一週可跑 `Prompts/04 退修準備`；當天可跑 `Prompts/05 退修引導`。

沒有年度計畫，刻意的：「一年太長，而且不可能訂對。」

## 8. 任務、專案、人物（第 91 天起）

- **任務寫在任何地方都可以**：`- [ ] 內容`。大多數用 `Ctrl+Shift+I` 丟進收件匣。
- 格式：`📅 2026-10-20` 到期 · `⏳ 2026-10-18` 排定 · `⏫` 高優先 · `➕` 建立日（收件自動加）
- **專案**：[[指南針儀表板]] →「📁 新專案」→ 筆記最上面會印出它的標籤，例如 `#project/腎臟學會投稿`。任何任務加上這個標籤就會出現在專案頁。
- **人物**：「👤 新人物」→ 標籤 `#p/王醫師`。想到「下次要跟他講」→ 寫成 `- [ ] 講 X #discuss #p/王醫師`，開會前打開他的頁面就全在那裡。
- [[任務儀表板]]：已逾期、今天、未來 7 天、待討論（依人）、高優先未排日期、收件匣、這週完成。
- 它是**推薦引擎**，不是執行清單。挑好之後排進行事曆的時間塊。「電腦是大腦，筆記本才是清單。」

不需要 Tasks 外掛：Dataview 讀得懂同一套 emoji 格式。

## 10. 跟 AI 一起用

所有 AI 工作都寫在 `Life OS/Prompts/`，一件事一則，列在 [[助理]]。用法：在 Claude Code 說
**「讀 `Life OS/Prompts/<檔名>`，照它的 Prompt 段落做。」**

| Prompt | 做什麼 | 會寫入嗎 |
|---|---|---|
| 01 晨間啟動 | 昨晚訊號＋今天三件事 | 不會 |
| 02 夜間教練 | 一個亮點、一個問題、一個 5 分鐘小動作 | 經你同意後追加 |
| 03 每週回顧 | 用你的話回顧一週、提議下週意圖 | 經你同意後追加 |
| 04 / 05 | 退修準備／退修引導 | 05 經你同意後追加 |
| 06 任務分流 | 帶你跑 JEV 釐清，再幫忙寫專案描述 | 不會 |
| 07 / 08 | 會議準備／專案啟動 | 08 經你同意後追加 |
| 13 趨勢分析 | 哪一題在動、跟臨床負荷有沒有關 | 不會 |
| 14 今天什麼最重要 | 推薦 3 件事 | 不會 |
| 15 健康檢查 | 系統有沒有壞 | 不會 |
| 16 新手引導 | 陪你完成設定、改寫題目 | 經你同意後修改設定檔 |

每則 prompt 都有同一組規則：先讀再寫、先問再改、只追加、不讀臨床內文、**數字一律由程式算**（`python scripts/lifeos_status.py`），不讓模型心算。

## 11. 改設定

**唯一的設定檔是 [[Compass Config]]。** 改這裡，儀表板、夜間評分、模板、決策層全部跟著變，不需要改程式。

- **換題目**：改 `dq_questions` 的 `prompt`。保留 `id` → 歷史分數延續；改 `id` → 等於開新題目。
  寫題原則：「我今天是否盡力……？」、一題只問一件事、3–5 題。
- **換習慣**：改 `habits`。每季 3–5 個。
- **人生輪領域**：改 `wheel_areas` 的 `name`。`criteria` 是給決策層判斷「這則收件屬於哪個領域」的字詞——**寫成你自己會用的詞**，分類就會更準。
- **生日**：`birthdate: 1985-01-01` 這樣的格式。
- **提早解鎖**：改 `start_date`。但先問自己：每晚 30 秒是不是已經不用想了？

**這個設定檔是你的**：第一次部署之後，更新系統不會覆蓋你改過的版本（見第 12 章）。

## 12. 你的資料是安全的

- **日記只追加**：所有腳本只在標題底下加新行，不改、不刪任何既有文字。
- **臨床邊界（derived）**：程式只在你的電腦上數「🏥 臨床」區塊有幾筆，只把兩個數字寫進 frontmatter。個案內容從來不會進入任何 prompt、紀錄或網路。
- **部署不會蓋掉你寫的東西**：
  - 儀表板、views、prompts、手冊：每次更新都會換成新版（**不要手改**，要改請告訴 Claude 改 workshop 的 `vault-src/`）。
  - 設定檔、人生主題、核心價值、理想週、任務總表、看板：**只在第一次建立**。之後只要你改過，更新就會跳過它，並告訴你「kept（你改過）」。
  - 週記、季記、退修、人物、每日筆記：部署**永遠不碰**。
- **決策紀錄**：`Life OS/Meta/decisions.jsonl`（你的每一次同意／更正）、`calibration.json`（決策層的校準），都在你的 vault 裡，不上傳。

## 13. 疑難排解

| 狀況 | 原因與解法 |
|---|---|
| 儀表板只看到程式碼 | Dataview 沒開，或沒開 **Enable JavaScript Queries** |
| `Ctrl+Shift+Q` 沒反應 | QuickAdd 沒建 Macro，或沒點 ⚡，或熱鍵沒設（第 1 章） |
| 按鈕說「找不到 Life OS 收件」 | QuickAdd 選項名稱要一字不差 |
| 看板是一堆清單 | Kanban 外掛沒開 |
| 人生輪說沒有退修筆記 | 按「本季退修」建立，填 `wheel_*` 分數 |
| 週記嵌入顯示「找不到」 | 本季季記還沒建，按「本季」 |
| triage 每一題都問我 | 正常：決策層還冷。回答越多，它越少問 |
