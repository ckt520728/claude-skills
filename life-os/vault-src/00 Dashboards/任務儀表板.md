# ✅ 任務儀表板

這一頁是**推薦引擎**，不是執行清單。挑出今天要做的，再排進行事曆或紙本時間塊。
「電腦是大腦，筆記本才是清單。」

任務寫在任何地方都可以（`- [ ] ...`），多數丟進 [[任務總表]] 的收件匣，之後再釐清。
格式：`📅 2026-10-20` 到期 · `⏳` 排定 · `⏫` 高優先 · `#project/專案-slug` · `#p/人名-slug` · `#discuss`

```dataviewjs
await dv.view("Life OS/Meta/views/gate", { layer: "tasks", view: "tasks", args: { section: "all" } });
```

> [!info] 收件匣的釐清交給 JEV 決策層
> 在終端機跑 `python scripts/triage.py`：一則收件一次 `jev.decide()` 呼叫，問完
> 可行動嗎／哪一類／哪個領域／多急／多耗神／歸到哪。你的每個回答都是一筆校準資料。
> 見 [[使用手冊]] 第 5 章。
