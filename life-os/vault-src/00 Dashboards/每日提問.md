# 🌙 每日提問

「我今天是否盡力……？」1–10 分，來自 Marshall Goldsmith《Triggers》。**問努力，不問結果**：
生病還是慢跑了 3 公里可以是 10 分；原訂 12 公里因為不想跑而砍成 6 公里，可能只有 5 分。

題目是每日筆記裡的 `dq_*` 數字屬性。要改題目，只改 [[Compass Config]] 的 `dq_questions`。

## 趨勢（近 90 天）
```dataviewjs
await dv.view("Life OS/Meta/views/dailyquestions", { days: 90 });
```

## 一件明確的風險
1–10 分會引來 Goodhart's Law：為了數字好看而評分。唯一的防線是題目問**努力**。
如果分數在漲、生活卻沒變好，該做的是重寫題目，不是更努力刷分。
