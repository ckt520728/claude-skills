# 🔥 習慣畫布

資料就是每日筆記裡的 `habit_*` 勾選（夜間評分時一起問）。沒有 App、沒有通知、沒有連續天數羞辱。
習慣和解釋「為什麼那三天沒做」的日記放在同一個地方，這就是它比習慣 App 好用的原因。

## 近 8 週
```dataviewjs
await dv.view("Life OS/Meta/views/gate", { layer: "habits_weekly", view: "habits", args: { days: 56 } });
```

## 近 2 週
```dataviewjs
await dv.view("Life OS/Meta/views/gate", { layer: "habits_weekly", view: "habits", args: { days: 14 } });
```

## 換掉追蹤的習慣
1. 打開 [[Compass Config]]，改 `habits` 清單（保持 `habit_` 開頭）。
2. 結束。今晚開始就問新的，這頁自動跟上。每一季只追 3–5 個。
