# 🔧 設定清單

一次做完大約 10 分鐘。每一步都附「做完怎麼確認」。詳細圖文在 [[使用手冊]] 第 1 章。

## 第 1 天就要做（其他都可以等）

- [ ] **1. 開啟 Dataview**：`設定 → 第三方外掛 → Dataview` 打開 → 進 Dataview 設定，打開 **Enable JavaScript Queries** 和 **Enable Inline JavaScript Queries**。
  確認：[[指南針儀表板]] 顯示表格而不是程式碼。
- [ ] **2. QuickAdd「Life OS 夜間評分」**：`設定 → QuickAdd → Manage Macros`（新版：Add Choice 選 **Macro**）
  → 名稱填 `Life OS 夜間評分` → 加一個 **User Script**：`Life OS/scripts/nightly.js` → 回到 Choice 清單，點 ⚡ 讓它變成指令。
- [ ] **3. QuickAdd「Life OS 收件」**：同上，名稱 `Life OS 收件`，User Script 選 `Life OS/scripts/capture.js`，點 ⚡。
- [ ] **4. 熱鍵**：`設定 → 快捷鍵` 搜尋 `QuickAdd: Life OS 夜間評分` → 設 `Ctrl + Shift + Q`；`QuickAdd: Life OS 收件` → 設 `Ctrl + Shift + I`。
  確認：按 `Ctrl + Shift + Q`，跳出第一題。
- [ ] **5. 改成你自己的題目**：打開 [[Compass Config]]，把 `dq_questions` 的 4 題草稿改成你真的想每晚面對的問題（3–5 題，問努力不問結果），`habits` 留 2–3 個。
- [ ] **6. 今晚評分一次**。30 秒。明天 [[指南針儀表板]] 就有第一個點。

## 可以晚點做

- [ ] **7. 填 `birthdate`**（[[Compass Config]]）→ 啟用 Memento mori。
- [ ] **8. 開啟 Kanban 外掛**（已安裝）→ [[專案看板]]、[[創作看板]] 會變成看板。
- [ ] **9. 第 61 天之前**：寫 [[人生主題]]、[[核心價值]]、[[理想的一週]]（第一次退修時一起寫也可以）。

## 刻意不需要的外掛

| 上游 Compass 用 | 這裡的替代 | 理由 |
|---|---|---|
| Templater | 儀表板的「前往」連結自己建檔、自己填日期 | 你的舊日記模板就是死在 Templater 沒裝 |
| Periodic Notes | 同上（週記、季記、退修都從 [[指南針儀表板]] 開） | 少一個依賴 |
| Tasks | Dataview 讀同一套 emoji 格式（📅 ⏳ ⏫ ➕） | Dataview 已經要開了 |
| Agent Client | 在 Claude Code 裡請它讀 `Prompts/` 某一則 | 你已經有 obsidian MCP |
| life-os-app, SEO | 不採用 | 這個 vault 用不到 |
