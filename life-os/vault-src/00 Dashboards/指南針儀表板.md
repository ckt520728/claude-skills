# 🧭 指南針儀表板

> [!tip]- 這一頁是空白或只看到程式碼？
> 需要 **Dataview**（已安裝，但目前關閉）：`設定 → 第三方外掛 → Dataview` 打開，
> 再到 Dataview 設定開啟 **Enable JavaScript Queries**。詳見 [[設定清單]]。

這一頁全部從你已經在寫的筆記產生。改題目、改習慣、改人生輪領域，都只改 [[Compass Config]]；這一頁會自己跟上。

```dataviewjs
await dv.view("Life OS/Meta/views/quicklinks");
```

## 🌙 每日提問
```dataviewjs
await dv.view("Life OS/Meta/views/dailyquestions", { days: 30 });
```

## 🔥 習慣
```dataviewjs
await dv.view("Life OS/Meta/views/gate", { layer: "habits_weekly", view: "habits", args: { days: 21 } });
```

## 🎡 人生輪（本季退修）
```dataviewjs
await dv.view("Life OS/Meta/views/gate", { layer: "retreat", view: "wheel" });
```

## ✅ 今天的任務
```dataviewjs
await dv.view("Life OS/Meta/views/gate", { layer: "tasks", view: "tasks", args: { section: "today" } });
```

## 🗂️ 看板
```dataviewjs

```
