# 🤖 助理 —— Prompt 庫

每一件重複的工作寫成一則 prompt，放在 `Life OS/Prompts/`。用法：

1. 在 Claude Code（或任何有 obsidian MCP 的 agent）裡說：
   **「讀 `Life OS/Prompts/02 夜間教練.md`，照它的『Prompt』段落做。」**
2. 它會先讀、再提議；任何寫入都先給你看，等你說好。

每則 prompt 的 `risk` 屬性告訴你它可能碰什麼：`read-only` 只讀、`append` 只追加、`edit` 會提議修改。

```dataview
TABLE WITHOUT ID file.link AS "Prompt", purpose AS "做什麼", when AS "何時", risk AS "風險", layer AS "層"
FROM "Life OS/Prompts"
SORT file.name ASC
```

## 分工：誰做哪一種事

| 層 | 做什麼 | 例子 |
|---|---|---|
| **[C] 程式** | 算術、日期、平均、連續天數、解鎖 | 7 日平均、第幾天、80% 一致性 |
| **[D] JEV 決策層** | 從固定選項中挑一個標籤，附上校準過的信心 | 這則收件可以行動嗎？哪一類？多急？ |
| **[G] 大型語言模型** | 對話、反思、綜整、寫成人話 | 夜間教練、週回顧、退修引導 |

Prompt 都是 [G]。它們**不自己算數字**、**不重新判斷標籤** —— 數字由 [C] 算好、標籤由 [D] 給好，它們負責講成人話。
