Covariates in Causal Inference 因果推論中的共變量

A covariate (X) does two different jobs. In a randomized experiment it buys precision: smaller variance, more power. In an observational study it buys identification: adjusting for the right X removes confounding bias. Each strategy below is paired with a live simulation you can rerun.

The core idea · design ↔ analysis duality

Control covariates by design, or adjust for them in analysis

The same covariate can be handled before treatment is assigned (you control the assignment mechanism) or after the data come in (you model the outcome). Modern theory shows the two are close substitutes, and the strongest practice uses both.

Design stage · discrete covariate

Blocking (stratified randomization) 區組 / 分層隨機化

Split units into blocks by a prognostic covariate (here, sex) and randomize within each block. Treatment proportions are then fixed in every block, so the block effect can no longer leak into the treatment–control difference by chance.

  • Unbiased for the ATE, like complete randomization (CRE).
  • The variance lost is the between-block part. The more the covariate predicts the outcome, the bigger the gain.
  • Analyze as blocked: weight block-specific differences by block size.

Simulation: n = 80, half male. Y(0) = 10 + δ·male + N(0,1), constant effect τ = 2. Same finite population, re-randomized many times.

Design stage · continuous covariates

Rerandomization with Mahalanobis distance (ReM) 重隨機化

Draw a random assignment, compute the covariate imbalance, and accept it only if it is small. Otherwise discard it and draw again (Morgan & Rubin 2012; Li, Ding & Rubin 2018).

M = τ̂ₓᵀ Cov(τ̂ₓ)⁻¹ τ̂ₓ accept if M ≤ a τ̂ₓ = x̄(treated) − x̄(control)
  • Still unbiased for the ATE, but the sampling distribution becomes a narrower, non-Gaussian, truncated shape. Inference must account for that (use the ReM asymptotics or a randomization test that repeats the same rule).
  • Duality (Li & Ding 2020): as a → 0, ReM with a plain difference in means behaves like CRE followed by Lin regression adjustment. Compare the blue and green curves.

Simulation: n = 100, two covariates, outcome Y(0) = X₁ + 0.8X₂ + N(0, 0.6²), τ = 1. Under a χ²₂ reference, acceptance probability pₐ gives threshold a = −2 ln(1 − pₐ).

Analysis stage · randomized experiment

Regression adjustment done safely: Lin (2013) 全交互作用迴歸調整

The problem (Freedman 2008): classic ANCOVA, Y ~ Z + X, uses one pooled slope. If the slope differs by arm (effect heterogeneity) and the arms are unequal in size, the pooled slope over-corrects the smaller arm. Its variance can then be larger than not adjusting at all.

The fix (Lin 2013): center the covariate and interact it with treatment, then use Huber–White (HC2) standard errors.

Yᵢ = α + τZᵢ + (Xᵢ − X̄)β + Zᵢ(Xᵢ − X̄)γ + εᵢ τ̂_L = τ̂ − (n₀/n·β̂₁ + n₁/n·β̂₀)ᵀ τ̂ₓ
  • Asymptotically never less precise than the unadjusted difference in means, even when the model is wrong.
  • Sandwich SEs are consistent or conservative, so 95% intervals keep coverage.
  • With a 1:1 design, ANCOVA's errors in the two arms cancel and it matches Lin. Move the slider away from 0.5 to watch ANCOVA break.
Worked example from the Lin reference. 80 surgery vs 20 drug patients; age slope is 10 under surgery, 2 under drug; drug arm is 4 years older than average. A pooled slope ≈ 0.8·10 + 0.2·2 = 8.4 subtracts 4 × 8.4 = 33.6 points from the drug arm when the truth calls for 4 × 2 = 8. The interacted model gives each arm its own slope.

Observational study · design + analysis

Propensity score, overlap, IPW and AIPW 傾向分數 · 逆機率加權 · 雙重穩健

Without randomization, X affects both who gets treated and the outcome. Identification needs two assumptions:

  • Ignorability: Z ⫫ (Y(1), Y(0)) | X. No unmeasured confounders.
  • Overlap: 0 < e(X) < 1, where e(X) = P(Z=1 | X).
IPW: τ̂ = mean[ ZY/ê ] − mean[ (1−Z)Y/(1−ê) ] AIPW: τ̂ = mean[ μ̂₁ − μ̂₀ + Z(Y−μ̂₁)/ê − (1−Z)(Y−μ̂₀)/(1−ê) ]

AIPW is doubly robust: it is consistent if either the outcome model μ̂ or the propensity model ê is right. In this simulation the outcome models are deliberately wrong (linear, while the true curve is exponential) and the propensity model is right, so plain regression stays biased while IPW and AIPW recover the truth.

Design-stage tools: match treated units to controls on ê(X) before looking at outcomes, and trim units with ê outside [α, 1−α]. Trimming changes the target population, so report it.

Data: X ~ N(0,1), logit e(X) = γX, Y(0) = X + 0.6eˣ + N(0,1), Y(1) = Y(0) + 2 + X. True ATE = 2. n = 1,000, 300 replications.

Covariate selection · graphical criteria

What not to adjust for 不該控制的變數

Adjusting for every available variable is not safe. Pearl's back-door criterion: the adjustment set must block every back-door path into Z and must contain no descendant of Z. Pick a structure and see the estimate with and without adjusting for the third variable (one large sample, n = 20,000, true effect of Z on Y = 1).

Post-treatment variables (mediators, compliance, survival to follow-up) need principal stratification or mediation analysis, not ordinary covariate adjustment.

Analysis stage · high-dimensional X (p large)

Double machine learning 雙重機器學習

When p approaches or exceeds n, OLS fails. Plugging a regularized learner straight into the outcome model shrinks the confounder coefficients, and that regularization bias leaks into the treatment effect.

DML (Chernozhukov et al. 2018) is a machine-learning version of Frisch–Waugh–Lovell:

1 · Predict Y from XResidual Ỹ = Y − m̂(X), fitted on other folds
2 · Predict Z from XResidual Z̃ = Z − ê(X), fitted on other folds
3 · Regress Ỹ on Z̃The slope is θ̂. Errors multiply: n^(−1/4)·n^(−1/4) = n^(−1/2)
  • Neyman orthogonality: first-order errors in the nuisance models do not move θ̂.
  • Cross-fitting: each residual comes from a model that never saw that unit, removing overfitting bias.
  • Still needs overlap. Propensities near 0 or 1 make the variance blow up.

Simulation: n = 500, p = 40. Five covariates drive both Z and Y; θ = 1. Learner: ridge regression with penalty λ. 5-fold cross-fitting. 150 replications.

Raise λ: the naive plug-in drifts away from θ = 1 because shrunken confounder coefficients leave confounding in the residual. DML bias grows much more slowly because it depends on the product of the two nuisance errors. Push λ past about 50 and both learners become poor, so DML also loses coverage: orthogonality forgives moderate nuisance error, not a bad learner.

Unmeasured confounding · sensitivity analysis

How much hidden bias would overturn the result? 敏感度分析

E-value (Ding & VanderWeele)

E = RR + √(RR·(RR − 1)) (use 1/RR if RR < 1) Bounding factor B = RR_EU·RR_UD / (RR_EU + RR_UD − 1)

The curve shows every pair of confounder strengths (U→treatment, U→outcome) that could just explain away the point estimate. Any confounder below the curve cannot. The E-value is where the curve meets the diagonal. Default values are the lipid-drug cohort example from the reference (RR 0.45, CI 0.32–0.63 → E = 3.87, CI limit 2.55).

Rosenbaum Γ for matched pairs

1/Γ ≤ odds of treatment within a matched pair ≤ Γ Γ = 1 ⇔ no hidden bias (as in a randomized trial)

Worst-case one-sided p-value of the Wilcoxon signed-rank test, normal approximation: under Γ the chance a pair's difference is positive is at most Γ/(1+Γ). Γ* is where the curve crosses α = 0.05.
