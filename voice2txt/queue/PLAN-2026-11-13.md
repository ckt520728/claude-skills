## Wave C (added 2026-11-13 after the user chose "push-to-talk hotkeys + tray" from the Typeless gap analysis)

Evidence: `verification/typeless-feature-inventory-2026-11-13.md`. User choice: only option 1 of the four gap groups (insert-anywhere/context/隨便問, auto dictionary/audio options, dashboard/retention/theme stay as listed next steps).

Decisions:
- T07 hotkeys: pure state machine in `voice2txt/hotkeys.py` (testable without Win32), WH_KEYBOARD_LL hook that never swallows keys (AltGr safety) and injects a no-op VK 0xFF before a consumed bare-Alt key-up so the menu bar does not activate. Defaults: dictate RightAlt (+ legacy Alt+Shift+Space), translate RightAlt+RightShift. Hold >= 0.35 s = hold-to-talk; shorter = tap-to-toggle; 0.15 s prefix grace so the longer combo wins.
- T08 tray/indicator/login: ctypes Shell_NotifyIcon (no pystray/Pillow, no new dependencies, no network), stdlib-generated .ico, WS_EX_NOACTIVATE indicator, HKCU Run key, `--minimized`.
- Order: T07 -> T08 (both edit desktop.py) -> audit C -> T05 docs -> T09 final rebuild -> final audit. T07 starts only after audit A1 has finished reading desktop.py.

## Wave D (user request after the wave C close-out: "continue with the remaining Typeless gaps")

Scope = the three gap groups not chosen in wave C: (1) insert-anywhere + context + 隨便問, (2) auto dictionary + sounds + mute-others, (3) 洞察 dashboard + retention + appearance.

Decisions:
- No UI Automation (no comtypes; stdlib only). Context = foreground window title + process name + app category table, plus the selected text captured by Ctrl+C with clipboard save/restore (CF_UNICODETEXT only). This is a documented deviation from Typeless's UIA field capture.
- 隨便問 = new hotkey action 'ask' (RightAlt+Space), transcript -> LLM with TASKS['ask'] and the context; no Whisper fallback (shows transcript with a warning when no LLM).
- Paste-back keeps the focus guard; hotkey sessions paste by default; clipboard restored after paste.
- Auto dictionary learns only from edits made inside the Voice2Txt editor (we cannot observe edits in other apps without UIA); candidates need user acceptance.
- Mute-others via Core Audio COM through ctypes, default off, restore guaranteed.
- Stats: words = CJK chars + latin words; time saved uses a 40 wpm typing baseline (stated in UI).
- File ownership: T14 translation.py+context.py; T15 learning/sounds/audiofocus; T16 core.py+insights.py+theme.py; T17 desktop.py+run_desktop.py (+hotkeys.py for the 3rd action). T14/T15/T16 run in parallel, then T17, then audit E, fixes, docs T18, rebuild T19, audit F.

### Wave D amendments after audit E (planner decisions)
- Default 隨便問 combo is RightAlt+RightCtrl (Alt+Space opens the Windows system menu because the hook does not swallow keys). Old saved default is migrated.
- Narrow swallow rule added: only the non-modifier key that completes a configured combo containing Alt is swallowed (down + up); modifiers never. The "no key swallowed" invariant becomes "no modifier swallowed; only combo-completing non-modifier keys".
- Selection capture releases all held combo keys (incl. Alt) first, like the paste path; multi-segment paste-back is merged into one clipboard write.
