# Voice2Txt 使用者手冊

版本：2026-10-18（Windows 桌面版）

Voice2Txt 把你說的話即時轉成文字，有三種模式：

| 模式 | 你說 | 畫面輸出 |
| --- | --- | --- |
| 繁體中文 | 中文 | 繁體中文（台灣用語） |
| English | 英文 | 英文 |
| 中文 → English | 中文 | 英文譯文（並另外顯示中文原文供核對） |

### 設計原理：兩階段處理

```
第一階段  Whisper 語音轉文字（本機）  ──▶  原始轉錄：「嗯，那個，我們明天下午三點，不對，是四點開會」
第二階段  LLM 整理與去雜訊            ──▶  整理結果：「我們明天下午四點開會。」
          （中翻英模式同時翻譯）       ──▶  “We have a meeting tomorrow at 4 p.m.”
```

- **Whisper 負責「聽」**：把聲音忠實轉成文字，連贅詞、重複、口誤都一起轉出。
- **LLM 負責「整理」**：去除贅詞（嗯、呃、那個、um、uh）與重複字詞；說話者明確更正時（「不對」「我是說」「sorry, I mean」），只保留更正後的內容；依上下文修正錯字、補上標點；中翻英模式同時翻成英文。
- **不增刪資訊**：LLM 被要求保留所有事件、否定、日期、時間、地點、數量與名稱。「禮拜一，不是禮拜二」屬於資訊，會完整保留，不會被當成口誤。
- **原始轉錄一定保留**：畫面下方「Whisper 原始轉錄」區與歷史紀錄都會保存整理前的文字，方便核對 LLM 有沒有改錯。

測試中，同樣含贅詞與口誤的 5 段語音，**僅 Whisper 5 段都未通過**，加上本機 LLM 整理後 5 段都通過（見第 10 節）。

語音辨識在你的電腦上完成，不需要訂閱或帳號。預設的 LLM 也在你的電腦上執行（Ollama）；只有在你自行設定雲端備援時，才會把 Whisper 轉錄的**文字**送到 OpenAI 或 Google。

---

## 1. 系統需求

| 項目 | 需求 |
| --- | --- |
| 作業系統 | Windows 10／11 64 位元 |
| 麥克風 | 任一 Windows 可辨識的麥克風或耳機麥克風 |
| 磁碟空間 | 一般版約 1 GB；GPU 版約 7.8 GB |
| 顯示卡（選用） | NVIDIA 顯示卡可使用 `medium`／`large-v3` 模型，速度快很多 |
| 本機 LLM（選用，中翻英建議） | [Ollama](https://ollama.com) 與本機模型，預設 `gemma4`（約 9.6 GB） |

## 2. 安裝與啟動

1. 取得整個 `Voice2Txt` 資料夾（內含 `Voice2Txt.exe` 與 `_internal`）。**請整個資料夾一起複製或移動**，只複製 exe 無法執行。
2. 雙擊 `Voice2Txt.exe`；若從專案資料夾執行，也可雙擊 `啟動桌面版.cmd`。
3. 本程式沒有數位簽章，Windows 可能出現 SmartScreen 藍色視窗。確認來源可信後，按「其他資訊」→「仍要執行」。

## 3. 第一次設定

開啟後切到 **「字典與設定」** 分頁：

1. **Whisper 模型**：決定辨識品質與速度。
   - `small`：一般電腦建議。
   - `medium`／`large-v3`：需要 NVIDIA 顯示卡（運算裝置選 `cuda`）。
   - `base`：最省資源，品質較低。
2. **運算裝置**：`cpu` 任何電腦都能用；`cuda` 需 NVIDIA 顯示卡與 GPU 版程式。
3. **文字處理**：
   - `Whisper + LLM 整理`：**偵測到 Ollama 時自動成為預設**。三種模式都會經過 LLM 整理，中翻英品質也最好（見第 5 節）。選此項時 Whisper 固定用 CPU，建議 `small`。
   - `僅 Whisper`：不需其他軟體，速度最快，但保留所有贅詞與口誤，中翻英也較常漏譯。
4. **麥克風**：選擇要使用的麥克風；`系統預設` 會跟隨 Windows 設定。
5. **個人字典**（選用）：見第 7 節。
6. 按 **「儲存設定與字典」**，再按 **「載入 / 下載模型」**。畫面底部狀態列會顯示目前使用的模型與翻譯順序，例如：
   `small / cpu 已就緒；Whisper 轉錄 → Ollama gemma4:latest → OpenAI gpt-6-luna (high) → Gemini gemini-3.8-flash (low) → Whisper 結果。`

程式內已附模型，載入不需下載。若選了未附的模型，第一次會從網路下載，可能需要數分鐘。

## 4. 開始使用

1. 回到 **「即時語音」** 分頁，在左上方選擇模式。
2. 按 **「● 開始錄音」**，然後自然說話。
3. 說話停頓約半秒，就會輸出一段文字；連續說話時最長每 8 秒輸出一段。
4. 按 **「■ 停止錄音」**。按鈕會顯示「處理尾段…」，等它恢復，最後一句才會完整出現。
5. 文字可直接在畫面上修改，接著可以：
   - **複製全文**：複製到剪貼簿。
   - **匯出 TXT**：存成 UTF-8 文字檔。
   - **清空畫面**：只清除畫面，歷史紀錄仍保留。

### 在其他程式中使用（快捷鍵）

- 在任何程式中按 **`Alt + Shift + Space`** 開始錄音，再按一次停止。
- 勾選 **「完成後貼入原視窗」**，每段文字會自動貼到你開始錄音時所在的視窗（例如 Word、LINE、瀏覽器）。
- 為避免貼錯地方，**只有原視窗仍在最前面時才會貼上**；切換過視窗就會略過，文字仍保留在 Voice2Txt。
- 自動貼上會覆蓋系統剪貼簿的內容。
- 若狀態列顯示「快捷鍵已被其他程式使用」，請改用錄音按鈕，或關閉占用該快捷鍵的程式。

## 5. LLM 整理與備援機制

選擇 `Whisper + LLM 整理` 時，每一段語音的處理流程如下：

```
語音 ─▶ 第一階段 Whisper 轉出原始轉錄
            │
            ▼  第二階段：依序嘗試，成功就停
        ① 本機 Ollama（預設 gemma4）         逾時 20 秒
            │ 失敗
        ② OpenAI gpt-6-luna，推理強度 high   逾時 30 秒，需 API key
            │ 失敗
        ③ Gemini gemini-3.8-flash，強度 low  逾時 30 秒，需 API key
            │ 全部失敗
            ▼
        ④ 只用 Whisper：
           繁體中文／English → 直接使用原始轉錄（未整理）
           中文 → English   → Whisper 直接語音翻譯（離線）
```

- 沒有填 API key（也沒有環境變數）的雲端服務會自動略過；取消勾選也可以停用。
- 某個 LLM 失敗後，會**暫停 60 秒**不再嘗試，避免每一段都要等它逾時；60 秒後自動重試，恢復後就回到 Ollama。
- 狀態列會顯示每段實際使用的引擎，例如 `整理：OpenAI gpt-6-luna (high)（備援啟用：Ollama gemma4:latest：…）`。看到「備援啟用」代表前面的 LLM 有問題；顯示 `整理：Whisper` 代表該段沒有經過 LLM。
- 即使全部失敗，錄音也不會中斷，原始轉錄會存入歷史紀錄。
- 載入模型時若 Ollama 沒有回應，程式仍會完成載入，並先改用備援。

### 5.1 設定本機 Ollama（建議）

1. 從 <https://ollama.com> 下載並安裝 Ollama。
2. 開啟「命令提示字元」，輸入 `ollama pull gemma4`，等待下載完成（約 9.6 GB）。
3. 確認 Ollama 正在執行（工作列右下角有 Ollama 圖示）。
4. 重新開啟 Voice2Txt。若你從未手動選過文字處理方式，會自動改用 `Whisper + LLM 整理`。也可以在設定頁的「① 本機 Ollama 模型」輸入其他已下載的模型名稱。

Voice2Txt 只連線到本機（`127.0.0.1:11434`），會拒絕名稱含 `cloud` 或指向遠端的 Ollama 模型。

### 5.2 設定雲端備援 LLM（選用）

只在前一個 LLM 失敗時使用，**需要你自己的 API key，並依用量付費**。這不是訂閱，但會產生費用；這兩個模型目前沒有免費額度。可以兩個都設定、只設定一個，或都不設定。

| 順序 | 服務 | 預設模型 ID | 預設推理強度 | 申請 API key |
| --- | --- | --- | --- | --- |
| ② | OpenAI | `gpt-6-luna`（GPT Luna） | `high` | <https://platform.openai.com/api-keys> |
| ③ | Gemini | `gemini-3.8-flash`（Gemini Flash 3.8） | `low` | <https://aistudio.google.com/apikey> |

Gemini 預設用 `low`：實測 `high` 每段可能超過 30 秒而逾時，而 `low` 的整理品質在測試句中沒有差異。

設定步驟（「字典與設定」分頁）：

1. 在 `② OpenAI 備援`、`③ Gemini 備援` 兩列分別貼上 API key。模型 ID 與推理強度已填入預設值，可自行修改（例如改用 `gemini-4-argon`）。
2. 不想使用某個服務時，取消該列的勾選。
3. 按「儲存設定與字典」，再按「載入 / 下載模型」。
4. API key 會以 Windows DPAPI 加密保存，只有你的 Windows 帳號能解開。也可以不填，改設定環境變數 `OPENAI_API_KEY`、`GEMINI_API_KEY`。

**隱私提醒**：使用雲端備援時，該段的 Whisper 轉錄文字會傳到 OpenAI 或 Google；錄音本身不會上傳。內容涉及病患、個資或機密時，請取消兩個雲端備援的勾選。

## 6. 歷史紀錄

- **「歷史紀錄」** 分頁會列出每一段結果（時間、模式、前 80 字）。
- 雙擊任一筆即可在「即時語音」分頁查看全文；中翻英的紀錄會一併顯示中文原文。
- **「刪除所有歷史紀錄」** 會永久刪除，無法復原。

## 7. 個人字典

在「字典與設定」輸入常用的專有名詞，用逗號分隔，例如：

```
Voice2Txt, 林口長庚, Alzheimer, 失智症, Gemini
```

字典有兩個用途：提示 Whisper 這些詞可能出現（最多前 1000 字），並在 LLM 整理時作為優先拼法（最多前 500 字），讓 LLM 把聽錯的專有名詞改正。它**不是強制替換**，不保證每次都正確。

## 8. 資料與隱私

| 資料 | 位置 |
| --- | --- |
| 設定、字典、加密的 API key | `%LOCALAPPDATA%\Voice2Txt\settings.json` |
| 歷史紀錄 | `%LOCALAPPDATA%\Voice2Txt\history.sqlite3` |
| 錄音 | **不保存**，只在記憶體中暫存 |

在檔案總管網址列輸入 `%LOCALAPPDATA%\Voice2Txt` 即可開啟。想要完全重設時，關閉程式後刪除整個資料夾。

## 9. 疑難排解

| 狀況 | 處理方式 |
| --- | --- |
| LLM 整理後意思不對 | 對照畫面下方的「Whisper 原始轉錄」；若常發生，改用 `僅 Whisper` 或換一個 Ollama 模型 |
| 「開始錄音」按鈕是灰色 | 先到設定頁按「載入 / 下載模型」，等狀態列顯示「已就緒」 |
| 無法開啟麥克風 | 到 Windows「設定 → 隱私權與安全性 → 麥克風」允許桌面應用程式使用；或在設定頁換一支麥克風 |
| 處理速度不足，錄音已停止 | 電腦跟不上辨識速度。改用較小模型（`small`／`base`），或有 NVIDIA 顯示卡時改用 `cuda` |
| 狀態列一直出現「備援啟用：Ollama…」 | 確認 Ollama 正在執行，並在命令提示字元執行 `ollama list`，確認模型名稱與設定頁相同 |
| 雲端備援出現 `HTTP 400`／`401` | API key 錯誤或已失效，請重新貼上 |
| 雲端備援出現 `HTTP 429` | 超過用量上限或帳戶額度不足；到 Google AI Studio／OpenAI 後台確認方案與帳單。程式會暫停該服務 60 秒後再試 |
| 雲端備援出現 `HTTP 404` | 模型 ID 打錯，或你的帳號沒有該模型的使用權 |
| 選 `cuda` 後載入失敗 | 需要 NVIDIA 顯示卡及 GPU 版程式；否則改用 `cpu` |
| 中文出現簡體字 | 請使用「繁體中文」模式；中翻英的中文原文也會轉成繁體 |
| 自動貼上沒有作用 | 錄音期間不要切換視窗；部分以系統管理員身分執行的程式不接受一般程式貼上 |
| 關閉視窗沒反應 | 程式正在處理尾段，請等它完成後再關閉 |

## 10. 已知限制

- 這是「分段近即時」，不是逐字串流；每段約延遲「停頓時間 + 辨識時間」。
- **翻譯結果請務必核對**，尤其是數字、時間、日期與否定句。測試中，Whisper 直接翻譯曾漏掉「開會」「明天」；本機 Ollama 在測試句中表現最好，但測試只有 3 句合成語音。
- 尚未完成真人長時間錄音與跨程式貼上的完整實測。
- LLM 整理實測（5 段含贅詞與口誤的合成語音，只計 LLM 時間）：

  | 方式 | 通過 | 每段時間 |
  | --- | --- | --- |
  | 僅 Whisper | 0／5 | — |
  | 本機 Ollama gemma4 | 5／5 | 約 0.6 秒 |
  | OpenAI gpt-6-luna (high) | 5／5 | 約 2–3.3 秒 |
  | Gemini gemini-3.8-flash (low) | 2／2（另 3 段因帳號額度 HTTP 429 未回應） | 約 2.6 秒 |

  Gemini 的速度在同一天內變化很大（2.6 秒到超過 60 秒）；超過 30 秒會逾時並自動改用下一個方式。
- LLM 仍可能改錯意思，重要內容請對照「Whisper 原始轉錄」。

## 11. iPhone 版

iPhone 版是獨立的原生 App，在手機上辨識，支援相同三種模式；結果透過複製或分享送到其他 App。目前**尚未完成編譯與實機測試**，需要 Mac 與 Xcode 才能安裝。iPhone 版目前只有第一階段（Whisper），沒有 LLM 整理與雲端備援，中翻英使用 Whisper 直接翻譯。安裝步驟見 [ios/README.md](ios/README.md)。
