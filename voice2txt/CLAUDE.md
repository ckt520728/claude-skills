# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Voice2Txt: a Typeless-like, subscription-free voice input tool with three modes — Traditional Chinese transcription (`zh`), English transcription (`en`), and Chinese speech → English (`translate`). A fourth mode, 隨便問 (`ask`, ask-anything: the spoken transcript is a question or instruction answered by the LLM), exists in `core.MODES` and is started by a hotkey or the mode box. Two deliverables:

- **Windows desktop** (Python 3.9, Tkinter, faster-whisper/CTranslate2) — `voice2txt/`, packaged with PyInstaller into `dist/Voice2Txt/`.
- **iPhone** (SwiftUI + WhisperKit 0.9.4, on-device CoreML) — `ios/`. Never compiled yet: no Mac/Xcode in this environment.

User-facing docs (`README.md`, `STATUS.md`, `ios/README.md`) are in Traditional Chinese; keep them in Chinese. `STATUS.md` is the acceptance ledger; `handoffs.md` is the session-to-session handoff log. Original goal prompt: `2026 voice2txt_r1.md`.

## Commands

Use `.build-venv` (full deps + PyInstaller). `.venv` is a minimal leftover env.

```powershell
.\.build-venv\Scripts\python.exe -m unittest discover -s tests -v              # all tests (~0.2s, no model needed)
.\.build-venv\Scripts\python.exe -m unittest tests.test_core.CoreTests.test_chunker_preserves_every_sample_and_flushes_tail   # single test
.\.build-venv\Scripts\python.exe run_desktop.py                                # run desktop app from source
.\.build-venv\Scripts\python.exe run_desktop.py --self-test out.json --audio tests\fixtures\chinese.wav --mode translate --model small [--device cuda] [--llm-model gemma4:latest] [--cloud Anthropic:low --cloud OpenAI:high --cloud Gemini:low] [--vocabulary "..."]   # keys from ANTHROPIC_API_KEY/OPENAI_API_KEY/GEMINI_API_KEY; missing key = skipped
PYTHONPATH=. .\.build-venv\Scripts\python.exe scripts\benchmark_refine.py small   # Whisper-only vs each LLM on tests/fixtures/disfluent-*.wav -> verification/refine-*.json
# wave D check scripts: check_context_capture.py (Ctrl+C selection capture + clipboard restore), check_audiofocus.py (mute/restore a child process's audio session), check_wave_d.py (Tk UI + cross-process hold/paste checks)
# check scripts (each writes a verification/*-2026-11-13.json; they use temp registry keys and a temp LOCALAPPDATA):
.\.build-venv\Scripts\python.exe scripts\check_hotkey_hook.py      # real WH_KEYBOARD_LL hook + injected keys -> verification/hotkey-hook-*.json
.\.build-venv\Scripts\python.exe scripts\check_tray_indicator.py   # tray, close-to-tray, indicator, Run key roundtrip, --minimized
.\.build-venv\Scripts\python.exe scripts\check_single_instance.py  # second launch exits and shows the first window
.\.build-venv\Scripts\python.exe scripts\check_desktop_settings.py # settings roundtrip incl. Anthropic row, DPAPI key, env fallback
.\.build-venv\Scripts\python.exe scripts\check_ios_project.py      # structural check of ios/ project; NOT a compile
.\.build-venv\Scripts\python.exe scripts\make_icon.py              # regenerates voice2txt/assets/voice2txt.ico (stdlib only)
powershell -NoProfile -File scripts\build_windows.ps1 [-IncludeGpu] > build.log 2>&1   # PyInstaller onedir build -> dist\Voice2Txt (don't use PowerShell *> redirection: stderr + ErrorActionPreference=Stop aborts it)
.\.build-venv\Scripts\python.exe scripts\download_models.py small medium       # Systran/faster-whisper-* -> models\whisper-<size>
```

`--self-test` is how packaged builds are verified: it writes a JSON report with `stage` checkpoints, `desktop_ui`, `ok`. A failed run leaves `stage` at the last reached step — use it to locate crashes (e.g. native DLL faults). Run it against `dist\Voice2Txt\Voice2Txt.exe` too, not just source.

`scripts/benchmark_*.py` / `smoke_*.py` run real inference on `tests/fixtures/*.wav` and write results into `verification/*.json`. `tests/fixtures/quality-corpus.json` holds the zh→en quality cases with keyword checks (times, negations, quantities).

There is no linter or formatter configured.

## Architecture (desktop)

- `voice2txt/core.py` — engine-agnostic pieces:
  - `Chunker`: turns the mic stream into segments; cuts at ~0.5 s pauses (RMS < 0.006) with a hard max length, and `flush()` must return the tail so no sample is lost (tests assert exact sample conservation).
  - `WhisperEngine`: wraps `faster_whisper.WhisperModel`. `translate` mode uses Whisper's built-in `task='translate'`; `zh` output goes through OpenCC `s2twp`. The user dictionary is passed as `initial_prompt` (≤1000 chars). Accepts an injected `model` for tests.
  - `bundled_model()` / `preferred_settings()` resolve models relative to `sys._MEIPASS` (PyInstaller) or repo root; `models/whisper-<size>` is used if `model.bin` exists, otherwise faster-whisper downloads it. CUDA auto-selects medium/large-v3 only when `gpu/nvidia` exists and a GPU is detected.
  - `configure_cuda()` adds `gpu/nvidia/*/bin` (pip-installed cuBLAS/cuDNN from `requirements-gpu.txt`) to the DLL search path for this process only.
  - `Store`: SQLite history at `%LOCALAPPDATA%\Voice2Txt\history.sqlite3`, with an in-place `source` column migration.
- **Core design (user-specified, 2026-10-18): two stages.** Stage 1 is Whisper speech→text. Stage 2 is an LLM that organizes and denoises the transcript in *every* mode: it removes fillers and repeats, applies explicit self-corrections, fixes misheard words, and adds punctuation. In `translate` mode it also translates. The raw Whisper transcript is always kept as `source`. Prompt rules live in `RULES`/`TASKS` in `translation.py`. Keep the rule that a contrast or negation ("Monday, not Tuesday") is information, not a self-correction: both cloud models dropped it before that rule was added.
- `voice2txt/translation.py` — stage 2, with fallbacks. Every backend exposes `refine(text, mode, vocabulary)`. Fixed order: Ollama → Anthropic (`claude-sonnet-5-5`, `low`; `claude-opus-5-5` is the documented alternative) → OpenAI (`gpt-6-luna`, `high`; `gpt-6.1-terra` is an alternative) → Gemini (`low`) → Whisper only. Order and defaults are in `CLOUD`. `LocalTranslator` talks to **local Ollama only** (`127.0.0.1:11434`, proxies disabled, 20 s translate timeout) and rejects cloud/remote models. `CloudTranslator` is the opt-in backup: Anthropic Messages API (raw urllib, `anthropic-version: 2026-10-21`, `output_config.effort`, no `temperature`/`thinking`; refusal and `max_tokens` stops raise), Gemini `generateContent` (`thinkingConfig.thinkingLevel`) or OpenAI Responses (`reasoning.effort`); defaults are in `CLOUD`. The Anthropic path is pinned by unit tests only; no live call has been made (no key was available on 2026-11-13). `TranslatorChain` tries each translator in order and pauses a failed one for 60 s. `build_translator(ollama_model, clouds)` sorts the clouds into the `CLOUD` order, and a failed Ollama `prepare()` pauses Ollama instead of failing the model load. `decode_segment()` is the single place mode routing happens. With a chain, Whisper transcribes (`zh` for zh/translate, `en` for en) and the chain refines. `zh` output is re-run through OpenCC. If every LLM fails: zh/en return the raw transcript, and translate falls back to Whisper `task='translate'`. `DecodeResult.error` is set only if that fails too. **Wave D:** every backend's `refine(text, mode, vocabulary='', context=None)` passes an optional context dict `{app, title, selection, category}` into `instructions(mode, vocabulary, context)` (system text only; request shapes are otherwise unchanged; selection truncated to 2000 chars). `TASKS['ask']` makes the transcript a question/instruction: answer in the transcript's language, apply the instruction to the selected text when it refers to it, no preamble; the ASR clean-up rules are still prepended but the task overrides 'return the text unchanged'. `decode_segment(engine, audio, mode, vocabulary='', translator=None, context=None, ask_language='zh')`: for `ask`, Whisper transcribes in `ask_language` (the dictation language), the chain refines with the context, `zh` output goes through OpenCC, and there is **no Whisper fallback**: if every LLM fails it returns the transcript with `warning='沒有可用的 LLM，顯示原始轉錄'` (not an error). For zh/en/translate the context only adds a one-line format hint by `category` (code: plain text; email/document: keep paragraphs; chat: short).
- `voice2txt/keystore.py` — Windows DPAPI (`CryptProtectData`) wrapper so cloud API keys are not stored as plain text in `settings.json`; env vars `ANTHROPIC_API_KEY`/`GEMINI_API_KEY`/`OPENAI_API_KEY` are used when the field is empty.
- `voice2txt/desktop.py` — Tk `App`. Threads: sounddevice callback → `audio` queue (bounded; overflow stops recording explicitly rather than dropping audio) → collector feeds `Chunker` → `jobs` queue → single `_decode` worker → `events` queue → `_poll` on the Tk thread (only place UI is touched). Global hotkeys now come from `hotkeys.py` (see below); optional paste-back only fires if the original window still has focus and is deferred until every hotkey key is released (`paste_decision`). Settings in `%LOCALAPPDATA%\Voice2Txt\settings.json`. The engine choice is saved as `translation_backend_v2`. Its values are `LLM_REFINE`/`WHISPER_ONLY`; the earlier saved values `本機 Ollama`/`Whisper` are mapped through `LEGACY_BACKENDS`. While no choice is saved, startup probes Ollama `/api/tags` and defaults to `LLM_REFINE` (the older `translation_backend` key is intentionally ignored). Cloud settings are stored per provider under `cloud`, with DPAPI-encrypted keys; the old single `cloud_provider` keys are migrated on load. `LLM_REFINE` forces CPU Whisper. **Wave D settings keys:** `context_aware` (default on; send window title + app name for zh/en/translate), `hotkey_paste` (default on; hotkey sessions paste back), `sounds` (default on), `mute_others` (default off), `appearance` (`系統`/`淺色`/`深色`), `retention` (`1 週`/`1 個月`/`3 個月`/`永久`, default `永久`; `Store.prune` runs at startup and on save), `dictionary_auto`, `dictionary_ignored`, and `hotkeys_version` (`HOTKEYS_VERSION` = 2, read with a safe int; `migrate_hotkeys` moves the old `ask` default `RightAlt+Space` to `RightAlt+RightCtrl` only while the version is below 2, so a deliberate later `RightAlt+Space` is kept). Tabs: 洞察, 即時語音, 歷史紀錄, 字典與設定. `ask` sessions: `_begin_ask` checks the clipboard format read-only first (non-text content -> no keys injected, status line says capture was skipped), then releases every held combo key including Alt via `release_held_modifiers`, calls `PushToTalk.mark_synthetic_release` for them, and captures the selection with Ctrl+C on a background thread; capture is skipped when Voice2Txt itself is foreground (the editor selection is used). Deferred pastes for the same target are merged by `merge_pastes` (joined with `\n`) into one clipboard write and one Ctrl+V; the clipboard text is saved before and restored `PASTE_RESTORE_MS` (700 ms) after (CF_UNICODETEXT only; the status line says when restore was skipped). `ask` history rows are filterable and excluded from insights. Auto dictionary: after a session the editor text is snapshotted; on editor FocusOut or settings save `learning.candidates` runs and candidates need 加入/忽略.
- `voice2txt/hotkeys.py` — Typeless-style push-to-talk. `PushToTalk` is a pure state machine with an injectable clock (unit-testable without Win32): defaults `DEFAULT_HOTKEYS` in `desktop.py` = dictate `RightAlt` + legacy `Alt+Shift+Space`, translate `RightAlt+RightShift`; hold ≥ 0.35 s = hold-to-talk (stop on release), shorter = tap-to-toggle; 0.15 s prefix grace so the longer combo wins; only the combo that started a session can stop it by tap (button-started sessions: any combo). `LowLevelKeyboardHook` (WH_KEYBOARD_LL, own thread) **never swallows a modifier** (`NEVER_SWALLOW_VKS`, AltGr safety); the only swallow is the narrow rule added in wave D: the non-modifier key whose key-down completes a configured combo containing Alt (e.g. `LeftAlt+Space`) is hidden from the foreground app (down and matching up) so the system menu does not open, and the hook has exactly two return paths (swallow or `CallNextHookEx`). A swallowed key never updates `GetAsyncKeyState`, so a lost key-up is recovered by a repeat timeout (1.2 s without key-down/up after auto-repeat has been seen; T22 restricts this to keys that have auto-repeated, because a key that never repeats would otherwise be dropped after 1.2 s). `PushToTalk.mark_synthetic_release(vks)` makes physical sampling ignore keys we released with injected key-ups until a real key-up/key-down arrives. Defaults also include `ask` = `RightAlt+RightCtrl`; before a consumed bare-Alt key-up it injects a no-op VK 0xFF so the menu bar does not activate (best-effort). Also: `_sync_physical` drops a key whose key-up was lost (1.2 s; only for keys seen physically down), 1.5 s continuation window, a hook watchdog/liveness probe gated on recent user input (a probe resets the system idle timer, so it must not run while idle), `conflicting_combos`/`TYPELESS_WARNING` (Typeless intercepts Right Alt), `ComboCapture` for the settings UI. Settings keys: `hotkeys`, `dictation_language`, `close_to_tray`, `start_at_login`.
- `voice2txt/context.py` — Win32/ctypes only. `foreground_window()`, `window_info(hwnd)` (title, process name), `categorize(process_name, title)` (code/email/document/chat/other table), `capture_selection(hwnd, timeout=0.4)` (Ctrl+C with CF_UNICODETEXT clipboard save/restore; skipped, with a reason from `capture_skip_reason`, when the clipboard holds non-text data), `foreground_context(capture=True)`. **No UI Automation**: the context is window title + app name + category + the Ctrl+C selection; fields of other apps are not read.
- `voice2txt/learning.py` — pure. `candidates(original_segments, edited_text, known_terms)` diffs model output against the user's edited text (difflib, CJK per character, latin per word); `merge_vocabulary(manual, auto)` (manual first, max 1000 chars). It only sees edits made in the Voice2Txt editor; it does not learn from edits in other apps.
- `voice2txt/sounds.py` — stdlib `wave` generates start/stop/error tones into `%LOCALAPPDATA%\Voice2Txt\sounds`; `play(name, enabled)` uses `winsound` and never raises.
- `voice2txt/audiofocus.py` — Core Audio via ctypes COM (no comtypes/pycaw). `mute_others(own_pid)` mutes other processes' non-system sessions on the default render endpoint and returns a `Handle`; `restore(handle)` is idempotent and also runs from atexit. A force-killed process cannot restore, and Windows remembers per-app mute (the manual tells the user to unmute in the Volume Mixer).
- `voice2txt/insights.py` — `count_words` (CJK characters + latin words), `compute(rows, today, typing_wpm=40)` (time saved = words / 40 wpm minus actual dictation seconds, streaks, per-day counts), `heatmap_cells(by_day, today, weeks=26)`. `ask` rows are excluded by the caller.
- `voice2txt/theme.py` — `CHOICES` (`系統`/`淺色`/`深色`), `resolve`, `apply` (ttk style + widgets); `LIGHT`/`DARK` palettes.
- `voice2txt/tray.py` — ctypes `Shell_NotifyIcon` tray on a hidden top-level window (not message-only, so `TaskbarCreated` arrives); menu 開啟視窗 / 開始・停止錄音 / 結束; also receives the `Voice2TxtShowWindow` broadcast from a second launch (UIPI filter opened with `ChangeWindowMessageFilterEx`). `voice2txt/startup.py` — HKCU `...\Run` value `Voice2Txt` = `"<exe>" --minimized`. `voice2txt/assets/voice2txt.ico` is generated by `scripts/make_icon.py` and bundled via `--icon`/`--add-data`. `desktop.py` also has the `RecordingIndicator` capsule (WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW), close-to-tray, a named-mutex single instance, and `run_desktop.py --minimized`.
- `run_desktop.py` — entry point for both the app and `--self-test`.

## Architecture (iOS)

`ios/Voice2Txt/`: `AudioChunker.swift` (tail flush), `Transcriber.swift` (WhisperKit; model downloaded on first use, then on-device; `Record.source` keeps the Whisper text; translate mode falls back to WhisperKit `.translate` when every LLM fails), `Refiner.swift` (stage 2: `RefinePrompt` mirrors `RULES`/`TASKS` verbatim, `CloudRefiner` for Anthropic/OpenAI/Gemini, `RefinerChain` with a 60 s pause, `RefineSettings` in UserDefaults with API keys in the keychain; off by default, so the default path stays offline), `ContentView.swift` (iPad-aware layout, settings incl. LLM section), `Voice2TxtApp.swift`. The project targets iPhone and iPad (`TARGETED_DEVICE_FAMILY = 1,2`). `scripts/check_ios_project.py` verifies structure only (every `.swift` is in the pbxproj, orientation keys) and writes `verification/ios-project-structure-2026-11-13.json`; it is not a compile. `ios/Voice2Txt.xcodeproj` is hand-generated by `scripts/generate_xcode_project.py`; `ios/project.yml` is an XcodeGen alternative. Build commands for a Mac are in `ios/README.md`. Do not claim the iOS app builds or works until `xcodebuild` and on-device evidence exist.

## Build gotchas

- `scripts/build_windows.ps1` overwrites `msvcp140*.dll`/`vcruntime140*.dll` inside `dist\Voice2Txt\_internal` with the System32 copies. An Anaconda-sourced 14.27 runtime caused `0xc0000005` when CTranslate2 loaded the model. Keep this step.
- The build bundles `models\whisper-small` (needs `config.json`, `model.bin`, `tokenizer.json`, `vocabulary.txt`); `-IncludeGpu` also bundles `gpu\nvidia` and medium/large-v3 if present. `dist\Voice2Txt` must be moved as a whole folder.
- `models/`, `gpu/`, `tools/`, `build/`, `dist/`, `*.spec`, `*.wav` are gitignored (the test fixture `.wav` files are not tracked by git either). `Voice2Txt.spec` is generated; the build script passes flags directly.

## Project rules (from STATUS.md / README.md)

- No subscription. The default path is fully local (Whisper + Ollama). Cloud LLMs are only an opt-in backup that the user explicitly requested (2026-10-18), with a user-supplied, pay-per-use key. They send transcript text, never audio. Don't make cloud the default or send audio.
- User-facing manual: `USER_MANUAL.md` (shipped as `使用者手冊.md` in `dist`). Update it when UI or behavior changes.
- Typeless (`D:\Downloads\Typeless-2.8.2-x64-Setup.exe`) is reference only. It was unpacked statically with 7-Zip and its `app.asar` analyzed with the REA CLI (`tools/rea`, results in `verification/typeless-*.json`, `verification/typeless-reference.md`). Never run the installer or copy its code, icons, or servers.
- JEV workflow (2026-11-13): planner specs live in `queue/` (`PLAN-*.md`, `T*.json`); executors run on Sonnet (`claude-sonnet-5-5`); an independent auditor on Opus writes `verification/audit-*.json` (A1, A2, C, C2, C3, C4, D, E, E2, E3). A task counts as done only after an audit PASS; FAIL verdicts produce follow-up tasks (T03b, T10, T11, T12, T20, T21). Do not edit audit files.
- Acceptance is evidence-based: a successful build is not proof that it works. Record real inference/UI results in `verification/` and update `STATUS.md`. Still open: real-microphone and 30-min tests, cross-app paste, translation quality on small/CPU, and everything on iOS.
