離線使用與目前限制
首次載入網站與模型需要網路。模型與頁面快取完成後，設計可在離線時使用；瀏覽器可能在空間不足時清除快取，屆時要重新下載。從 Safari 加入主畫面後，快取可能需要重新準備。
這是瀏覽器內的 Whisper 轉錄，不使用桌機或雲端 LLM 整理。錄音停止後才辨識，無法在鎖屏或背景持續錄音。小模型可能漏字、誤辨或漏譯，重要內容請核對。


語音與轉錄不送到桌機或辨識伺服器。首次模型下載連線至 Hugging Face；網站託管服務只提供程式與靜態檔案。辨識使用 Whisper、Transformers.js、ONNX Runtime Web 與 OpenCC。開源授權
