# 桃園市醫療資源分佈分析 — 產出物

2026-08-19 一次分析工作的成果。用 Twinkle Hub MCP 查詢台灣政府開放資料
（data.gov.tw），回答桃園市的醫師人力、行政區院所分佈與診所密度三個問題。

檢討與踩坑紀錄見 repo 根目錄的
[`2026-08-19_Taoyuan_Health_Data_Lessons_and_Pitfalls.md`](../2026-08-19_Taoyuan_Health_Data_Lessons_and_Pitfalls.md)。

## 重新產生 Word 檔

```bash
pip install python-docx
python build_docx.py     # 輸出到腳本所在目錄
```

需要 `Microsoft JhengHei`（Windows 內建）；換平台時改 `build_docx.py` 頂端的 `CJK` 常數。

## 圖表頁

`taoyuan-health-dashboard.html` 是自包含的單一檔案（僅外連 Google Fonts），
直接用瀏覽器開啟即可。若要在本機以 server 方式檢視：

```bash
python -m http.server 8777
# 開 http://127.0.0.1:8777/taoyuan-health-dashboard.html
```

圖表以原生 SVG 繪製，無外部繪圖函式庫。配色取自 dataviz 的驗證過調色盤
（blue `#2a78d6` / orange `#eb6834` / aqua `#1baf7a`），明暗兩模式皆通過
色盲區辨（CVD ΔE）與對比檢查。

## 重要限制

政府開放資料**沒有**醫師專科別人數，也**沒有**行政區層級的醫師人數。報告第二、三部分
以健保特約院所家數與登記診療科別作為代理指標，**不可直接解讀為醫師人力分佈**。
細節見報告 §1.3 與 §4.2。
