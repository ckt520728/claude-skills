# Rigor Rubric — the pass/fail checklist for a synthesis note

Every synthesis note is graded against this by an independent checker (Phase 2). A note
"passes" only if there is **no rubric failure**; cosmetic fixes are allowed, a rubric failure
is not (it sets the trial's calibration outcome to y=0). Adapt the wording to the domain; keep
the intent.

## Core (always)
- **R-accuracy** — every quantitative claim (N, effect sizes, CIs, dates, frequencies) matches
  the **full-text methods/results**, not just the abstract. *This is the one that fails most.*
- **R-causal** — causal vs correlational is explicit; causal weight is attributed only to
  actual manipulations (stimulation, lesion, optogenetics), never to correlation or
  single-neuron geometry; reverse inference is flagged.
- **R-periodic** — for any oscillation/rhythm claim, periodic vs aperiodic (1/f) structure is
  separated; a shuffle-in-time spectral peak is never accepted as an oscillation.
- **R-nulls** — nulls, failed replications, and critiques are weighted alongside positive
  findings, not omitted.
- **R-paths** — every cited corpus path resolves to a real file; each cited filename's **actual
  title** was confirmed (no paper-identity conflation).
- **R-source-quality** — no non-peer-reviewed material (slide decks, unpublished notes) cited
  as evidence; external (non-corpus) citations are flagged as such.
- **R-no-double-count** — a preprint and its published version are not counted as independent
  evidence.
- **R-quotes** — quotation marks contain **verbatim** source text only; paraphrase is unquoted.
- **R-no-overclaim** — no overclaim of "enhancement"/consensus; contested claims are labelled
  contested.
- **R-tension** — advocacy and critique are held together, not flattened into one consensus.

## Distinctions the note must not blur (domain: neuro-oscillation reviews)
- **entrainment vs modulation** — phase-locking *during* drive vs after-effect that *outlasts*
  it (reserve "entrainment" for a driven oscillator that reverberates post-drive).
- **phenomenon vs mechanism** — a real behavioural window/effect ≠ an oscillation causing it.
- **generation vs function** — how a rhythm arises ≠ what cognitive work it does.

## Verdicts
- **ACCEPT** — no rubric issue, no fix needed.
- **ACCEPT-WITH-FIXES** — accepted; list the fixes. If any fix resolves a **rubric failure**
  (not merely cosmetic), the trial's outcome is still y=0 for calibration.
- **REVISE** — a load-bearing claim is wrong/unsupported; re-do before acceptance.
